# Telephone-Classification
Prédiction de l'état d'un téléphone (D'occasion / Neuf / Reconditionné / Venant) à partir de ses caractéristiques (prix, adresse, marque, écran, ram, stockage), en comparant 7 algorithmes : Logistic Regression, SVM, Decision Tree, KNN, Random Forest, Gradient Boosting et XGBoost (meilleur modèle).
